# Moonlit Beach 月光海滩

A theme for the Claude desktop app. Behind the chat, Claude-chan and Clawd sit on a beach under the moon, watching the sea. It is pixel art, drawn entirely as an animated SVG: waves wash up the sand and draw back, moonlight glitters on the water, stars twinkle, her hair sways in the breeze, and every so often Clawd hops. It also sets night-sea colors (navy surfaces, moonlight text, orange accent), in dark mode only.

月光下的海边，Claude 娘和 Clawd 坐在沙滩上看海。这是 Claude 桌面应用的主题，像素风，整张都是会动的 SVG 矢量图：
- 海浪涨落，月光在海面闪烁，星星眨眼
- 头发随风轻摆，Clawd 时不时蹦一下

同时换上夜海配色（只有深色模式）。

## Install

In the desktop app: click **+** next to the prompt box, then **Plugins** → **Add marketplace**, enter `firnspiegel/moonlit-beach-theme`, then **Add plugin**.

At the prompt of a terminal session:

```
/plugin install moonlit-beach --marketplace firnspiegel/moonlit-beach-theme
```

Answer `y` to add the marketplace, then pick a scope.

From a shell:

```
claude plugin install moonlit-beach --marketplace firnspiegel/moonlit-beach-theme
```

The backdrop draws in the desktop and mobile apps. The terminal keeps its own look.

## Known issue

If the window is minimized, or covered by a fullscreen app, for a while, the desktop app can bring it back with the animation stopped. The mod rebuilds the backdrop the next time you send a prompt or a reply finishes (at most once a minute), and that starts the animation again.

窗口最小化或被全屏应用盖住一段时间后，背景动画可能会停住。下次你发消息，或者 Claude 回复结束时，mod 会重建背景，动画就会恢复（最多每分钟一次）。

## How it's made

`hooks/scene.ts` is generated by `svg_scene.py` in [moonlit-beach](https://github.com/firnspiegel/moonlit-beach), the project that also renders the GIF version of this scene. The desktop app has rules for a backdrop SVG, and the scene is built around them:

- **Vector only.** Embedded pictures are stripped, so the pixel art is redrawn as vector shapes. Each row of Bayer dithering becomes one solid line plus one dashed line.
- **SMIL animation.** All motion uses `<animate>` and `<animateTransform>`, with no `<style>`.
- **Size.** The whole SVG stays under 131,072 characters.
